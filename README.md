# hdbapocalypse
A light survival game on surviving a HDB apocalypse in Singapore

- `index.html` is the landing page, and `play.html` is the game.
- Drop generated hero art in `assets/landing/` as `hero.webp` (16:9) and `hero-mobile.webp` (9:16). It replaces the placeholder art automatically.
- `.claude/skills/landing-page-design` is the design skill used for the landing page (MIT, from elayadesign/ai-design-skills).

See [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md) for the game design sketch.
